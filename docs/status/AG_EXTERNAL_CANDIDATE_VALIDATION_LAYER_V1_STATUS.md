# External Candidate Validation Layer — Status

Recorded: 2026-09-12
Scope: infrastructure only. No strategy was optimized, no candidate was invented, no
Demo/Live authority changed. `src/external_candidate/` is new; every reusable
dependency it has (fingerprinting, performance metrics, cost model, lifecycle
registry, economic gate) is imported, not re-implemented.

## Authority boundary this layer enforces

```
EXTERNAL RESEARCH (Gemini)
    hypothesis generation / parameter search / candidate selection
        v
REPOSITORY (this layer + existing R4/R5/R6 infrastructure)
    admission -> immutable version identity -> exact implementation
    -> external/repo parity -> canonical R5 evidence -> signed R6 evaluation
        v
EXECUTION (unchanged, unrelated authority — src/api/app.py
    ::authorize_demo_execution() remains the only gateway)
```

The external optimizer has no authority over an R6 verdict, lifecycle promotion, or
Demo/Live authorization. This layer performs no parameter tuning, candidate search,
or rule optimization; it validates a candidate that is already frozen elsewhere.

## What was built (`src/external_candidate/`)

| Module | Purpose | Reuses |
|---|---|---|
| `models.py` | `ExternalCandidatePackage` schema (`AG_EXTERNAL_CANDIDATE_PACKAGE_V1`): identity, structured rules, dataset partitions, holdout declaration, friction assumptions, provenance | dataset-field vocabulary mirrors `config/historical_datasets/*.yaml` |
| `admission.py` | `validate_external_candidate_package()` — fail-closed gate | `config/governance/strategy_lifecycle.yaml` for parent-version identity checks |
| `version_guard.py` | Rejects in-place mutation of an already-evaluated (strategy_id, version) | pure function, no new persistent store invented |
| `parity/signal_comparator.py`, `trade_comparator.py`, `economic_comparator.py`, `verdict.py`, `divergence.py` | Signal/trade/economic parity + first-divergence diagnostics + `EXTERNAL_REPO_PARITY_{PASS,FAIL}` / `NOT_PROVABLE_INCOMPLETE_EXTERNAL_EVIDENCE` verdict | `performance/calculator.py`, `performance/models.py` for all metrics |
| `oos_evaluator.py`, `walk_forward.py` | Aggregate already-resolved samples into OOS/walk-forward evidence for a frozen candidate; no re-fitting per window | `performance/calculator.py::compute_trade_metrics` |
| `friction.py` | Friction-stress capability + candidate-vs-signed-scenario compatibility classification | `performance/cost_model.py::FRICTION_SCENARIOS` verbatim — invents nothing for BASE/SEVERE |
| `evidence_envelope.py` | Binds every candidate evidence output to strategy/candidate/config/dataset identity | `post_asian_pilot.fingerprint.fingerprint()` |

Hard rules enforced in code (not just documented):
- `admission.py` rejects `candidate_frozen=False`, `holdout_used_for_optimization=True`,
  `rules_changed_after_holdout=True`, and any HOLDOUT/OPTIMIZATION dataset-range
  overlap, before any other check runs.
- `parity/verdict.py::compute_parity_verdict()` can never return PASS from aggregate
  economic agreement alone — a clean signal or trade comparator result is required.
- `version_guard.py` rejects a candidate reusing an existing (strategy_id, version)
  key under a different config fingerprint.
- `validation_framework/economic_gate.py` is untouched; a synthetic OOS/walk-forward
  evidence set generated by this layer, run against the real (still `PROPOSED`,
  unsigned) `config/governance/economic_gate_contract.yaml`, still returns
  `NOT_EVALUABLE_MISSING_SIGNED_THRESHOLDS` (`tests/test_external_candidate_
  governance_invariance.py`).

## Known remaining gaps (not built — out of this task's minimum-token scope)

- No CLI/script entrypoint wires a real Gemini export file into
  `ExternalCandidatePackage` yet (parsing is intentionally deferred until a real
  export format is seen — building a parser for an unseen format would be
  speculative).
- `friction.classify_friction_compatibility()` only compares pip-denominated
  spread/slippage against the one signed CONTRACT_CEILING scenario; a real unit
  conversion (e.g. price-denominated or per-lot-denominated external assumptions) is
  `FRICTION_TRANSLATABLE`, not automatically translated.
- `known_version_fingerprints` in `version_guard.py` is caller-supplied; no
  persistent (strategy_id, version) -> config_fingerprint ledger exists yet. Building
  one was not authorized by this task (would be a second identity store without
  owner review, the same class of risk WP0 already flagged once).
