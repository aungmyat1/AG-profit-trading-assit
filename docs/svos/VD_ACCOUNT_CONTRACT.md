# VD V1 virtual account contract

`VirtualAccount(AccountProfile, InstrumentMetadata)` is an isolated deterministic state reducer. The profile freezes starting balance and currency, permitted symbols, max open positions, per-symbol and aggregate exposure, margin mode if supported, mark-price source, and rounding rules. It receives validated fills and admitted market marks, never strategy decisions directly. The profile cannot relax SSC's own risk allocation or create a proposal; account limits may only reject or reduce an order under an explicitly frozen partial-admission rule.

`balance = starting_balance + realized_PnL - booked_fees`; `equity = balance + unrealized_PnL - accrued_costs`. Each position records side, quantity, average entry, initial/current stop, realized/unrealized P&L, cost basis, instrument metadata hash, and source fill IDs. P&L is calculated in instrument quote units then converted to account currency using a point-in-time admitted conversion observation; missing conversion makes cash P&L unavailable and blocks dependent sizing. Risk exposure is the sum of open loss-to-stop estimates plus pending-order reserved risk under a frozen aggregation rule. Stop gaps may exceed planned risk and must be represented as realized loss, not capped to a target R.

Margin is `UNSUPPORTED` until a verified instrument/broker-like margin specification and conversion source are frozen; a margin-dependent order then rejects. If supported later, snapshots include used/free margin and a deterministic margin-call rule. Max-open-position enforcement counts open positions and reserved eligible orders at validation and fill, preventing simultaneous over-admission. Position transitions are `FLAT → OPEN → PARTIAL → CLOSED`, with updates only from immutable fill/management events. Existing `svos.virtual_broker.VirtualAccount` is an R-unit summary and is not a cash/margin implementation.

Append an account snapshot after every fill, fee, mark, rejection affecting reservation, and terminal outcome. Snapshot identity binds event ID, account profile hash, ordered positions, balance, equity, exposure, margin status, and previous snapshot hash. Unknown price, FX conversion, contract size, or stale mark produces an explicit `UNAVAILABLE` field and blocks any dependent economic assertion; it is never replaced by zero.
